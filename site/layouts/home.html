Core Principles

Why Structured Data Streams?

⚡

No Dual-Write Problem

Writes hit exactly one place: the append-only stream. SQLite databases, Parquet tables, and caches update deterministically by tailing the log.

Learn more →
⏱

Time Travel & Instant Restore

To restore state at any position Q, pick the latest snapshot at P ≤ Q and replay forward. Snapshots also act as the retention anchor to trim old log segments.

Learn more →
📦

Efficient, Self-Describing Wire Format

1–2 byte type prefixes. Protobuf descriptors sent once in-band. Unknown fields are preserved, schema migrations happen in place, and ten-year-old segments remain decodable.

Inspect wire format →
🗄

OLTP & OLAP from One Stream

Serve indexed point lookups from SQLite with sub-millisecond local reads, while DuckDB and Spark query columnar Parquet snapshots generated from the exact same stream.

Explore projections →
📁

Filesystems as Tables: ObjectFS

ObjectFS expresses directory trees and inodes as proto messages over an SDS stream, projecting high-performance read-only EROFS images for containers.
